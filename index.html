Best way to use on iPhone

Add this page to the Home Screen, then create an iPhone Shortcut automation that opens this URL at the event time. When the page opens, tap Play / Unmute / PiP.

iPhone may block autoplay with sound or PiP without a tap. That is normal.

Notes

  • This page tries to play the HLS stream directly in Safari.
  • If PiP is supported, it will request Picture in Picture after playback starts.
  • If the stream URL changes in the future, update the STREAM_URLS list in this file.
