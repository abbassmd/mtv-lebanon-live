iPhone Safari Instructions

  • Use Safari - Not Chrome or in-app browsers

Shortcuts Automation Setup

  1. Open Shortcuts app
  2. Automation → + → Create Personal Automation
  3. Time of Day → Set to show time (e.g., 8:00 PM)
  4. Add Action → "Open URLs"
  5. Paste this page URL
  6. Turn OFF "Ask Before Running"
