How to use this on iPhone

  • Open this page in Safari, not inside another app browser.
  • Tap Start sound + PiP. That gives Safari the user gesture it needs.
  • If PiP does not start, tap Fullscreen first, then swipe Home.
  • For timed opening, use an iPhone Shortcuts automation to open this URL at show time.
Important: Home Screen web-app mode may break PiP on iPhone. Use normal Safari for PiP.

Reminder / calendar file

The calendar file can remind you and include this page URL, but Calendar itself cannot auto-tap PiP.

Suggested Shortcuts automation

Shortcuts → Automation → + → Create Personal Automation → Time of Day → choose your days → Add Action → Open URLs → paste this page URL → turn off Ask Before Running.

Then, when Safari opens, tap Start sound + PiP.
